🎬 MotionX

Create. Animate. Edit. Make it yours.

MotionX is an open-source video editing project inspired by motion graphics editors and modern mobile video editing apps. Built around Swift and iOS technologies, MotionX aims to bring powerful editing tools into one creative workspace.

🚧 Work in progress — MotionX is actively being developed. Some planned features may not be available yet.

✨ Planned Features

* 🎞️ Multi-track timeline — Arrange video, images, text, and audio.
* 🎯 Keyframe animation — Animate position, scale, rotation, and opacity.
* 🌀 Motion effects — Build creative effects and animated compositions.
* 🎨 Visual customization — Work with shapes, colors, masks, and blending.
* 🎵 Audio tools — Add music, sound effects, and audio adjustments.
* ⚡ Transitions and filters — Give projects a polished look.
* 📱 Multiple aspect ratios — Create vertical, square, and widescreen videos.
* 📤 Video export — Export finished projects when supported by the implementation.
* 💾 Project management — Save and continue editing projects.

🛠️ Built With

* Swift
* SwiftUI
* AVFoundation
* Core Animation
* TimelineKit

📋 Requirements

* iOS 18 or later
* Swift 6.2 or later
* Xcode compatible with the required Swift version

Build requirements may change as the project develops.

🚀 Getting Started

1. Fork or clone this repository.
2. Open the project in Xcode on a compatible Mac environment.
3. Resolve the project’s Swift package dependencies.
4. Select an iOS simulator or connected device.
5. Build and run the project.
